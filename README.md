# GoWorkBro

本地单机的生活自律应用（原生 Kotlin + Jetpack Compose）：单页五模块 —— 待办 / 习惯 /
喝水 / 倒计时 / 睡眠。**无账号、无云端同步**，数据只存本机 Room 数据库；手绘卡通
森林风 UI，全中文界面。

## 功能

- **待办**：不计时 / 正向计时 / 倒计时（10/20/30/45/自定义）；点按开始专注、点计时页的
  ✓ 标记完成，再点已完成的计时任务就是开始第二轮；长按卡片可拖拽排序，`⋯` 进编辑。
  已完成待办按天自动收起，保留为历史，一条不删。
- **习惯**：每日目标计数（自定义单位），每天自动重置；长按拖拽排序，`⋯` 进编辑。
- **喝水**：每日 ml 目标，快捷杯子（长按改容量），主页一键打卡，近 7 天柱状图。
- **睡眠**：一次睡眠一条完整记录（午觉和夜觉一视同仁），两步滚轮记录，滚轮下带
  今天/昨天/前天标注；按**起床那天**归档（昨夜 23:00→07:00 算今天，早上睁眼就是
  「已睡 8h」）；每天合计、≥7h 连续达标、平均每觉、近 7 天柱状图。
- **倒计时**：标题 + 目标时间，主页卡片显示最近一项的剩余时间。
- **专注番茄钟**：全屏正/倒计时；主页底部常驻进行中卡片。
- **数据纵览**：总专注统计、今日专注分布环形图、近七天睡眠时长（底部齿轮进设置）。
- **日历日**：所有打卡按自然日归档，跨 00:00 自动翻日（不再有 0–4 点算前一天的开关）；
  睡眠是唯一按「结束那天」归档的模块，理由见上。
- **备份 / 自动更新**：设置页可导出/导入全量 JSON 备份；启动时检查 GitHub Releases
  （可关闭），后台下载新版本 APK，主页横幅一键安装 —— 这是全应用唯一的网络用途。

## 构建

```bash
# JDK 21 + Android SDK 36；wrapper 自带 Gradle
./gradlew assembleDebug            # 调试 APK
./gradlew testDebugUnitTest        # 单元测试（Robolectric，全离线密封）
./gradlew assembleRelease          # 签名 APK（需 app/key.properties + jks）
```

签名：`app/key.properties` + `app/goworkbro-release.jks`（均已 gitignore）。
applicationId 沿用 `com.azarai.goworkbro`，可直接覆盖安装升级。
